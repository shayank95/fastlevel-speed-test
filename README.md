# FastLevel homepage: static performance test

A static, hand-coded rebuild of the https://fastlevel.co/ homepage, published only to measure page speed with Google PageSpeed Insights.

- This is not the FastLevel website and is not indexed (`<meta name="robots" content="noindex">`).
- Links point to the live site at https://fastlevel.co/.
- Contains only public website assets (HTML, fonts, images).
